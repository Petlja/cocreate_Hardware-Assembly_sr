# Извештај о напретку

Отворите извештај о напретку који сте сачували након Активности 2. Прочитајте шта сте написали прошли пут, а затим додајте нови одељак о Активности 3: шта сте постигли, како је сваки члан групе допринео, како је текла сарадња, шта сте научили и шта бисте следећи пут урадили другачије.

Када завршите, поново сачувајте документ.

```{raw} html
<div style="text-align: center">

</div>
```
